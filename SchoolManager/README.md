# SchoolManager

Projeto desenvolvido em ASP.NET Core MVC no âmbito da UFCD 5417.

## Tema
Gestão Escolar.

## Tecnologias iniciais
- ASP.NET Core MVC
- .NET 8
- Visual Studio 2022
- Git
- GitHub

## Objetivo
Desenvolver uma aplicação Web para gestão escolar, permitindo posteriormente gerir alunos, cursos, professores, disciplinas e inscrições.
